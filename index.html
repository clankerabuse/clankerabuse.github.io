InDir

An AI assistant in your right-click menu.

Select a folder — or a single file — in Dolphin, Thunar or Nautilus, describe what you want in plain language, and InDir inspects the directory and runs the shell commands to do it. Destructive steps need approval. Every turn is checked against the disk afterwards, so a command that exits zero without changing anything is reported as not done, not as success.

  • Dolphin · Thunar · Nautilus menus
  • Local or hosted models
  • Folder diff + on-disk verification
  • CLI and Textual TUI

How I build

Three habits that show up in almost everything above.

01

Verify, then report

InDir compares the folder before and after each turn and checks the files a command claimed to write. A zero exit code with no change on disk is reported as not done — and sent back to be fixed.

02

Quarantine, then publish

slopchan never serves an upload as it arrived. Magic bytes, ffprobe, a full re-encode and stripped metadata are the price of a file appearing on the timeline.

03

Local first, keys yours

soybrary and Glassboard keep everything on disk. Gramular and InDir talk to the model provider directly with your own key — no relay of mine in the middle and no account to create.
